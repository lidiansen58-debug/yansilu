## 尚未通过的发布门槛

安装版启动后出现 Windows 安全中心的公共网络访问权限弹窗。原生窗口输入、保存及正常关闭重开尚未验收，不能将只读后端检查或构建成功记作这部分通过。

computer-use 的系统权限交互限制要求人工处理该弹窗；尝试关闭测试进程并移除测试调试参数后重启的操作也被自动审批拒绝，未执行，未改变系统权限。

原生验收仍在独立合成库中；原库选择的原始字节已备份。验收结束后须关闭自有测试进程并逐字节恢复原选择，不遍历或修改真实用户笔记。

## 通过门槛后的发布顺序

1. 在本机完成实际 CI 安装版的输入、保存、主题搜索、草稿恢复和关闭重开验收。
2. 公开上述同一份已验证文件，保持 Beta 预发布状态，不重新构建替换验收字节。
3. 先保存线上当前两份更新清单，再更新固定 Latest 入口的 Windows 通道，核对公开下载的大小、摘要、公钥签名及版本判断。
4. 官网候选 PR 通过后，使用既有 Cloudflare Pages `yansilu` 项目手动部署；验证线上首页、下载页及清单。

Mac 继续使用已有 Intel 原生验收的 Universal beta.3；Linux 保留现有 beta.3 手动下载。本次不宣称完成新 Mac/Linux 实机验收，也不启用其自动更新。
