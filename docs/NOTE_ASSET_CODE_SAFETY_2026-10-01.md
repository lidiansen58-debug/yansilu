# 移动与导出时保留附件代码示例

分支：`fix/note-link-selection`，接续笔记链接与代码边界修复。

## 行为

- 移动笔记或导出文章时，真实正文附件仍按新位置重写相对路径；行内、围栏和缩进代码里的附件示例以及转义的链接/嵌入保持原文。
- 附件扫描使用同样的代码与转义边界，代码里的不存在附件不再阻止文章导出，也不会作为真实附件复制。
- 扫描和重写都支持尖括号包裹的路径，保留带空格、中文和括号的文件名。真实链接显示文字中含行内代码时，附件仍可正常识别。
- 两次重写之间重新计算代码位置，避免前面的正文路径长度变化导致后面的代码范围偏移。

本轮改动仅在附件链接解析模块；重命名通过已有历史别名机制保持旧笔记引用有效，不重写引用笔记里的显示文字。没有调整界面或批量修改笔记库。

## 验证

- 659 项相关单元测试通过：编辑器/笔记/关系 570 项；附件、导出、目录生命周期、Markdown 和导入 89 项。加强的旧标题解析断言另行复验通过。
- 29 项相关浏览器用例通过：正文链接 17 项、编辑往返及草稿 5 项、关系安全 2 项、旧入口 4 项、真实目录菜单移动/删除 1 项。
- 真实临时笔记库测试覆盖目标笔记重命名、旧标题引用重新同步、引用笔记跨目录移动、旧文件消失与新文件落盘、独立关系 ID/类型/说明保留。
- 文章导出测试确认只复制真实附件，缺失的代码示例不会导致失败，导出正文保留代码原文；包含中文、空格和括号的路径可正确复制与重写。
- 编码检查无新增问题，`git diff --check` 通过。

使用临时笔记库，没有改动用户数据。本报告只覆盖相关测试；嵌套引用/列表中的代码、HTML 代码区域、真实输入法及长文档性能未验证。
