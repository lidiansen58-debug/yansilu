# 图谱价值与关联主线

## 目标与验收标准

本目标覆盖三个结果，不以修改文案或小型 Demo 测试通过代替完整验收。

1. 找回相关观点：从一条笔记查看真实关联、双方内容、关系方向和理由，能返回继续阅读；正文链接与手动关联同等对待。
2. 发现主题与思考缺口：群组是候选，不冒充已成立主题；提示必须说明对应的真实笔记或关系，用户能确认、补充或跳过。
3. 组织原创写作：从真实笔记组确认中心问题并带入写作材料，来源和理由可追溯，不凭连接数自动断言观点质量。
4. 降低关联门槛：先选目标再确认关系；能对照双方观点；搜索、保存、失败、重复关联和返回上下文反馈清楚。
5. 培养关联意识：形成判断后在自然下一步提供一次可跳过的关联建议，不以弹窗、强制步骤或数量指标催促用户。

- 复用现有搜索、关联事务、去重、Vault 隔离和写作入口。
