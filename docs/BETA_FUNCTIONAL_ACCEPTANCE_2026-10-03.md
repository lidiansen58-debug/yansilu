## 缺陷、修复与复验

1. 保存锁 FIFO：异步 realpath 在登记前让出导致顺序竞态。改为让出前解析规范路径；25 轮别名路径顺序回归、独立笔记/错误释放及真实 API 通过。
2. 显式笔记链接：读取成功仍停留首页，随笔/文献和未预加载目录没有正确加载。提取独立路由模块，读指定笔记并进入编辑器；三类保存/重载和缺失链接反馈通过。
3. 测试及代码组织维护：更新当前新建 ID、中文文案、公共编辑器 API 与异步等待；拆分写作篮会话模块。合入 main 的大模块冻结实际基线行数，未将调整阈值当作功能证据。
4. 移动后保存冲突：API 返回实际重写正文/fileRevision，客户端更新干净 Tab 保存基线，保留脏稿；附件移动后保存和真实 API 通过。
5. 新文章被填入示例书稿章节：两条前端创建路径传显式空目录，后端保留显式空结构；未传结构的旧 API 兼容。文章/两章/整稿闭环通过。
6. 文献模板预览切错选项且顶部按钮未同步无效状态：保留选项并禁用无效保存、显示原因；模板单元及当前 UI 复验通过。
7. 作者确认读写间外部编辑：PUT 带 expectedBody/expectedRevision/expectedVaultPath，检查当前库。真实浏览器先修改外部正文再放行确认，修复后拒绝；外部正文保留、authorship=false/status=draft。
8. AI 草稿采用后观点表单仍用旧基线：刷新观点工作区，同时保留人工表单草稿。改写理由可见；采用→改写→标记编辑→确认通过。
9. 作者确认取消提示写入旧 DOM：写入当前全局状态区，取消反馈可见。
10. 主题建议的人工修改被重绘丢弃：独立草稿模块保留名称/问题/素材理由；最后回归仍出现一次丢失，补重绘前采集已变化的 DOM 文本，即使 input 事件未被记录也保留。切页后真实保存核对通过，连续五轮重复通过，旧库 DOM 不会改变新库建议。
11. 不同主题串用旧写作项目：主题“开始写”替换素材并重建会话，“继续提纲/草稿”保留旧项目。相同素材的两个主题分别创建，已有项目不重复。
12. 切库保留旧主题建议：清空建议、忽略记录和加载状态；真实切库修复前失败、修复后通过。
13. 远端 AI 默认进入平台托管路线，模型框不可编辑：远端默认采用 Global Optimized/Balanced，与现有快速设置一致；真实配置 UI 测试/保存/重载通过。
14. 扩展图谱退出按钮被左侧栏遮挡：提高扩展图谱层级，实际普通点击退出成功；仍低于弹窗层级。
15. 加载中关闭建议弹窗无效，迟到详情可能恢复：关闭时结束加载并使详情请求 token 失效；浏览器持有真实响应再关闭/切换/放行通过。
16. 建议弹窗人工改写被后台重绘恢复旧值：独立模块在相同建议及相同服务端基线时保留未提交文本；保存后新基线、切换建议、关闭或切库不沿用旧稿。统一回归修复前保存了旧文本，修复后 canonical 保存为人工文本；相应单元通过。
