# 选中文字关联与编辑选区修复

基线：main `823566e7`（PR #206 已合并）；分支：`fix/note-link-selection`。

## 行为

- 选中单行普通文字后插入笔记链接，原文字成为显示别名；保留选区两侧的空格，目标仍使用稳定笔记 ID。多段、代码或已有链接不作为新链接的显示文字。
- 正文在链接窗口打开后发生变化时，取消旧选区的替换，请用户重新选择；切换笔记或笔记库后的旧窗口不能写入新上下文。
- 修正富文本选区与 Markdown 位置之间的双向转换。临时标记仅插入未提交的文档副本，不改变编辑器正文；转换结果不一致时不使用该结果。
- 光标处于完整链接内时，不再把它识别成尚未完成的 `[[` 输入。
- 富文本导出的链接和标签包装在编辑正文中还原为正常 Markdown；同时映射选区偏移，避免含标签或链接时的光标偏移及换行拆开原文。

转换模块使用仓库内 ToastUI 3.2.2 的 ProseMirror 文档和转换器；升级编辑器时需复验选区与模式往返。源码与生成的 ToastUI bundle 同步。
