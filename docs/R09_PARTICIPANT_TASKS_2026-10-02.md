# 研思录试用任务

请用研思录把一份短材料整理成自己的观点，再写成一段能分享的文章。我们测试的是软件，不是你的能力；找不到入口、看不懂提示，都请直接说出来。

你可以使用应用内的帮助。遇到不明白的地方，先按自己的理解尝试；不必猜测我们想要的答案。不要使用私人资料、账号密码或 API 密钥。

## 准备

- 准备两三条自己的非敏感笔记，共约 300–800 字，例如读书随笔或工作观察。
- 本次使用单独的测试笔记库，不动你原有的笔记库。
- 不需要配置 AI、注册账号或购买服务。

## 先试一个小练习

找到应用提供的短练习，尝试完成它。做到哪里、哪里不明白，都可以停下来告诉我们。示例里的答案不算你的文章成果。

## 再用自己的材料

1. 记下一条内容，保存后离开它，再找到并打开。确认内容还在。
2. 用自己的话留下一个判断。让以后读到它的你能知道：它想回答什么问题，依据是什么，哪里还不确定。尝试从这个判断回到原材料。
3. 再留下一个相关判断，把两个判断关联起来，用一句话说明为什么有关。不确定关系类型时，按自己的理解选择即可。
4. 在知识网络里找到这两条笔记，打开其中一条。说说这个关系能怎样帮助你思考，而不只是看见一条线。
5. 围绕一个问题，把两三条观点组织成提纲，写一段自己的正文。至少一个段落能说明它用了哪条笔记作为依据。
6. 保存文章，离开后回来继续补一句话。把最终正文导出到测试笔记库以外的文件夹，打开导出文件，确认包含刚补的内容，而不只是提纲。
7. 看看在哪里能把文章发展成多章书稿。尝试新增一章、写一句正文并保存；这一步不要求写完整本书。

## 完成后聊一聊

- 哪一步最难？你当时以为它会做什么？
- 保存一条观点，与真正理解这条观点，有什么不同？
- 下次想继续写这篇文章，你会从哪里开始？

几天后，请再次打开测试库，找回一条旧观点和这篇文章，补充一点新想法并保存。我们会提前约好时间，不要求你每天使用。
