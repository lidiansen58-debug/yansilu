# Smart Notes Demo 使用帮助

Smart Notes Demo 用一组可操作的笔记，展示研思录怎样把卡片笔记写作法变成日常动作：

记录 -> 永久笔记 -> 关联 -> 主题 -> 写作

核心不是记得更多，而是**让笔记生长为思想**。

## 第一次体验

1. 在设置的帮助中确认导入示例，打开“00 动手练习：从材料写成短文”。
2. 从上方练习按钮逐步进入，用自己的话保存三个判断。正文链接只用于阅读参考。
3. 搜索并选择另一条练习笔记，保存一条带理由的关系。
4. 跟随练习进入写作，检查提纲来源，写一段自己的解释并保存。
5. 从写作的“更多”导出文章 .md，打开实际文件核对正文。回到同一笔记库可继续练习。

一次只做一个动作也可以。

想查完整操作说明，可搜索“研思录使用说明：从一条记录到一篇文章”。首次导入的新库中，这篇说明也是示例写作项目的当前正文：从“如何从主题索引进入写作中心？”继续写即可查看、修改和导出。重复导入会保留已有笔记和写作，不会覆盖用户的练习修改。

## 三类笔记

- 随笔：先抓住现场想法，之后再处理。
- 文献笔记：保留来源，用自己的话重说材料。
- 永久笔记：写成一条以后还能继续使用、修改或反驳的判断。

## 怎样关联

搜索并选择另一条永久笔记，选择关系类型，写一句为什么相关，然后保存。

- 支持这个观点：给出能支撑判断的理由，仍要核对证据。
- 提出不同看法：保留反方，检查原判断。
- 补充适用条件：说明判断的适用边界。
- 提供一个例子：把抽象判断放进具体场景。
- 只是有关：暂时只能确定有关，仍要把理由写清楚。

关联是双向可见的。关系理由比连线数量更重要。

## 怎样形成主题

当几条永久笔记能一起回答一个问题时，可以创建主题索引。先写中心问题，再选择关键笔记和阅读顺序。主题成熟后，可直接进入写作中心。

## 怎样开始写作

写作中心从主题和相关笔记开始：

1. 确认要回答的问题。
2. 选择真正需要的笔记。
3. 从主题点“开始写”，选择素材，再点“生成提纲”并手动整理。
4. 检查证据、反方和边界。
5. 保存草稿，重开续写，再从“更多”导出文章正文。

## AI 在哪里帮忙

AI 不增加一条独立流程，只出现在具体任务旁：

- 材料旁：帮我提炼，或提炼选中的一段。
- 关联时：补充少量候选笔记和推荐理由。
- 写作时：生成提纲，检查证据、反方和边界缺口。

所有 AI 结果都只是候选，可编辑、可忽略，保存前必须由用户确认。不配置 AI，也能完整使用研思录。

第一次使用 AI 时，进入“设置 -> AI 设置”。可选择本地 Ollama，或填写 OpenAI 接口兼容服务。

## 手机和电脑怎样配合

手机适合快速记录、拍资料和轻量查看；电脑适合转述、关联、主题和写作。手机保存的内容会进入电脑端首页继续整理。
