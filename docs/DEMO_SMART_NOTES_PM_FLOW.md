# Smart Notes Demo 数据说明

## 目标

这套数据不是《卡片笔记写作法》的书摘库，而是用原创、人话笔记展示研思录当前主流程：

```text
随笔 / 文献笔记
  -> 永久笔记
  -> 有理由的关联
  -> 围绕问题的主题索引
  -> 写作提纲和草稿
```

## 当前内容

- 1 条方法来源说明
- 3 条随笔，包含已处理和待处理状态
- 4 条文献笔记，包含已转换和待处理状态
- 14 条永久笔记，围绕同一条知识链形成三个可见的笔记簇：材料到判断、关系与复利、主题到写作
- 关系同时包含正文链接和人工关系；人工关系保留支持、反驳、限定、前后顺序和桥接等真实用途
- 3 个主题索引
- 1 个写作项目和对应提纲
- 1 篇短示例文章，以及 1 篇可在写作中心继续编辑的完整使用说明正文
- 7 条短导览笔记

## 内容范围

Demo 只讲一条连续的实践：

1. 随笔和阅读材料如何变成自己的判断。
2. 判断如何通过带理由的关系，形成可继续思考的知识网络。
3. 主题如何把这些笔记带入一份可追溯提纲。

不放入与主路径无关的主题，也不复刻原书内容。

## 使用说明正文

“研思录使用说明：从一条记录到一篇文章”保存在 Demo 数据中。首次导入时，它通过写作项目的草稿绑定功能成为示例写作项目的当前正文，可继续编辑、保存和导出。正文说明随笔、文摘与文献笔记、永久笔记、正文链接与人工关系、主题、文章及书稿，并引用实际存在的示例笔记。它区分原书启发与产品设计，不把软件字段说成原书规则。

重复导入保留已有写作项目、当前草稿与修改，只补缺失数据。因此旧库不会被这份正文覆盖；需要查看最新完整体验时使用一个新的测试库，或者在示例目录搜索这篇说明。

## AI 边界

AI 可用于材料提炼、候选关联、提纲和草稿检查。所有结果必须先让用户看见，可编辑、可忽略、可确认；不自动创建正式笔记、关系或文章。

## 维护方式

唯一数据源：

```text
scripts/smart-notes-demo-data.mjs
```

刷新 fixture：

```text
npm run demo:refresh
```

生成文件：

```text
tests/fixtures/demo-smart-notes-product-thinking/demo.json
```

不要手工维护多套 Demo，也不要把测试 Demo 混入真实用户 vault。
