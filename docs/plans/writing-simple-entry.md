# 最简写作入口

本次仅实现用户已确认的写作入口，不扩展 FCC、RAG、AI 设置或其他笔记、关联与图谱流程。

- 点击现有“新建主题”，直接打开现有主题页，无笔记数量前置要求，无输入弹窗。
- 仅一个必填输入：“想写什么？”，占位文案“写下一个问题，或一句自己的想法。”
- 输入内容作为之后可修改的文章标题；唯一主要操作“开始写”。
- “开始写”直接进入现有草稿页，不自动生成提纲或正文，不执行 AI。
- 零条或一条材料均可开始；通过现有“相关笔记”入口逐步补材料，也可移出最后一条。
- 空材料不阻拦、不告警、不催促；沿用现有正文编辑器与保存操作。
- 新文章与正文保存后可以重新打开并继续修改；材料和标题变动不丢正文，不绕过保存冲突保护。
- 不增加页面、弹窗、面板或用户概念；保留已有材料主题、提纲、图谱和 AI 流程。

验证包括入口与保存恢复单元测试、现有写作 API 回归、桌面和手机浏览器完整操作、材料增删与标题修改、失败重试，以及主题超过一页后仍可查找续写。按规范与需求两个维度 review，发现问题则修复，最多五轮，review 无待处理问题后停止。
