# 图谱：看得清、能操作、能进入写作

用户目标：优化示例图谱的布局、关系表达与操作，让普通用户理解这些笔记为什么有关、下一步可以做什么。基线 bf05ebf7；最多五轮规范与需求 review，无待处理问题后停止。

已复现：真实示例在永久笔记根目录有24条笔记、51条关系；其中39条是正文引用，12条为支持、反驳等具体关系。阅读档有13对标题重叠；低连接节点被缩成很小的点，默认阅读高亮还会淡化其他节点。连线端点与节点坐标一致，不是连线丢失。当前主题面板按每条笔记的一跳邻居形成22组高度重叠的材料，使用说明和目录引用使中心偏向说明文档。

## 改动范围

1. 图谱布局与阅读：为小、中、大图保留清楚可点的笔记节点，按标题和点击范围避让；小中图默认能读主要标题，放大后标题不叠。关系线与节点同步，减少夸张弯曲和装饰，点笔记/关系可查看真实对象和理由。缩放、拖动、筛选、返回仍保留位置与选择。
2. 任务表达：沿用三个入口，改成“查看关联 / 补充关联 / 整理主题”，各用现有提示说清一个可执行目的；去掉“靠近=更相关”“中心=更重要”的暗示。不新增面板或系统概念；类型筛选保留全部关系和正文链接。
3. 关联与主题：保留真实关系，不为美观虚构或自动写入连接。具体关系优先于导航引用参与主题推荐，减少高度重叠的笔记组；正文链接仍可检索、查看和用于材料。整理主题沿用现有选择材料、填写共同问题、确认并进入写作流程，材料和原文不被改写。没有主题推荐也能继续阅读、关联或从一个问题开始写作。
4. 示例与帮助：只修复与当前图谱流程直接有关的失真说明；保持普通用户无需 Key，AI 由用户主动启用。

## 验收

- 真实示例导入后可浏览：24条笔记和51条关系可核对，不造关系、不改用户正文。
- 桌面与窄屏阅读标题不互相覆盖，笔记可点击；不能出现线明显可见而端点难以找到的效果。
- 连线详情给出两端、关系类型、理由或正文来源；关系保存后立即可见，失败保留输入。
- 三个入口的名称、页面状态、说明和实际下一步一致；不要求理解“星系”“镜头”“缺口”等内部术语。
- 主题材料组去重，包含具体材料和关联依据；可修改共同问题并进入现有写作，保留笔记内容、作者确认及保存保护。
- 真实示例、小型孤立图、密集图与筛选后状态均有必要回归；无运行错误，无隐式模型调用。
- 按规范和需求独立review，发现问题修复后再检查，最多五轮。验证达标且无待处理项后停止，不扩展到其他模块或发布安装包。

所有新建或编辑文本使用UTF-8，写文件脚本显式指定UTF-8。截图和临时验证工具置于工作区外。
