# 核心写作保存与界面减法

基线：main 0a9e4d2b。用户确认本次先修跨页面续写保存，再落实浏览器验收指出的四项减法，完成后重新浏览器验收并 review 至无待处理问题。

1. 已保存文章离开写作到首页、笔记或设置后返回，可以继续修改并保存到同一正文；保留外部修改、笔记库切换及迟到响应的保护，不通过删除冲突检查解决。
2. 当前观点保存后只留下同一套观点内容；仅清理已确认属于自动模板的空“核心观点”占位，不删除用户写过的内容或来源。
3. 写作帮助明确可以先写、材料后补；手动起草没有提纲时不展示误导性的空提纲入口。已有材料主题的提纲流程保留。
4. 相关笔记在现有添加列表中提供就地确认并加入，不要求先返回打开笔记。继续执行作者确认和原创性检查；卡片只呈现标题与可读摘要，隐藏内部 ID、Markdown、内部注释，避免已选项重复出现。
5. 普通文章不默认显示章节管理；高级章节操作后置到现有“更多”，已有章节仍可选择、保存和导出。

不增加新面板、新入口或新用户概念；不接入 FCC/RAG 或修改 AI、关联、图谱流程。相关逻辑留在现有领域模块；中文及文档按 UTF-8 写入。

验证：跨页续写与冲突保护回归、观点正文及用户内容保留、材料原地确认与拒绝/失败处理、零材料写作、已有提纲和章节操作；桌面与手机实际浏览器走查；规范与需求两轴独立 review，修复后复查。
