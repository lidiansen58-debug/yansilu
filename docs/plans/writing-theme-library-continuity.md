# 图谱写作：重开后能找到已保存主题

Windows 测试包基线 `94b4bfb3`：从图谱确认材料、生成本地提纲并保存文章后，退出重开，主题库最初出现4个主题，加载完成却只剩3个。API 中主题和正文均完整保存。原因是主题列表随材料所在目录隐式缩小，刚保存在另一目录的主题被隐藏。

本轮只修复这一个续写入口：

- “主题库”列出当前笔记库中的全部主题，不再受选中目录或材料目录隐式筛选。
- 保留现有前三项、显示全部、搜索和继续草稿操作，不增加面板、入口或概念。
- 目录仍用于决定新主题与正文保存的位置；不迁移、改写已有主题或笔记。
- 保留分页、去重、过期请求和切换笔记库保护，不展示其他笔记库的数据。

验收：

1. 单元回归覆盖材料目录已有其他主题时，目录外的已保存主题仍可找到；分页和笔记库切换保护通过。
2. 真实示例图谱 → 确认材料 → 本地提纲 → 保存正文 → 重开写作 → 原主题继续草稿，在桌面和手机均保留正文及原草稿绑定，不创建重复文章。
3. 重新打包 Windows，在相同的隔离示例库和 WebView 配置中验证退出重开、原主题续写与再次保存。真实笔记库选择和原笔记、设置逐字节保留。
4. 独立规范与需求 review 无待处理问题后结束，不扩展到其他页面或公开发布。

新增文本使用 UTF-8；截图、包和临时工具位于仓库外。
