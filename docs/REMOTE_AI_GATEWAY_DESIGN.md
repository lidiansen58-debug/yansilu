# 远程 AI 兼容接口设计

## 用户配置

所有 OpenAI 兼容服务共用「远程 AI」入口，仅填写服务商提供的 API 地址、API Key 和模型名称／ID。地址可包含服务商要求的路径前缀；应用补全 `/chat/completions`，完整对话地址也可直接填写。模型 ID 原样传给服务商，不依据品牌替换或猜测。

完整流程：填写配置 → 允许发送所选内容 → 对话测试 → 保存 → 使用。连接成功必须获得实际模型回复；地址可访问或 GET 健康检查成功不能代替对话验证。更改地址、模型或密钥后，重新确认并测试。

## 服务差异

- 通用传输、Bearer 认证、模型映射、取消和超时由现有兼容适配器处理。
- 服务特有参数放在 `openai-compatible-request-profile.mjs`，依据已验证的接口地址启用。
- 当前仅 DeepSeek 官方域名启用其 JSON 和思考模式适配。第三方服务即使代理 DeepSeek 模型，也不会收到 DeepSeek 特有参数。
- 关联审阅缓存同时区分服务地址与实际模型。保持配置不变可命中缓存；同一兼容接口切换地址或模型时重新调用，避免复用前一服务的判断。
- 不因调用失败自动切换到另一个服务，也不为探测格式重复发送付费请求。
- 结构化输出、工具调用和用量统计的能力以具体服务文档与联调为准；“OpenAI 兼容”不等于每种扩展参数均受支持。没有计费数据时，不把占位估算解释为实际扣费。
